Overview

Why this page exists

This project's interactive tool is a Streamlit app on a free hosting tier, which sleeps after inactivity — so a first click can hit a 20–30 second cold start. Rather than rely on that alone, this page is a self-contained walkthrough of the pipeline, the model, and the tool itself, built with real output from the project's ETL runs and held-out test predictions. The live dashboard link above still works — this page just means the project holds up even if it's asleep when someone clicks through.

“Can machine learning help urban hotels forecast demand, pricing, and revenue performance more accurately than traditional forecasting methods?”

Architecture

The pipeline, end to end

Two years of raw PMS exports — reservations, daily stats by source/segment/room type, rate changes, and Medallia guest-satisfaction surveys — run through seven numbered ETL scripts into a single model-ready daily master dataset, which feeds four LightGBM models and the Streamlit tool.

01 Raw hotel data Reservations, daily stats, rate changes, Medallia — 2024–2025
02–06 ETL & cleaning Inspect → profile → clean reservations, daily stats, rates, surveys
07 Master dataset hotel_daily_master.csv — merged, model-ready
08–16 Feature engineering Holidays, weather, NYC events, STR comp-set, review sentiment (NLP)
11 LightGBM models Occupancy · ADR · RevPAR · Revenue → Streamlit app

The Tool

Inside the Streamlit app

The forecasting output is served as a multi-page revenue-manager tool. Seven pages, in the order they appear in the app's sidebar:

01
Dashboard

Landing KPI view — current occupancy, ADR, and RevPAR against trailing periods, with day-of-week filtering.

02
Forecast

The core deliverable — 30/60/90-day occupancy, ADR, and revenue forecasts from the LightGBM models, generated forward from the last known data point.

03
Performance

Reader-board style breakdown by booking source and room type — nights sold, occupancy, ADR, RevPAR, sellouts, and OOO-driven lost revenue.

04
Demand

Booking channel mix (OTA / Direct / GDS / Phone), lead-time distribution, and length-of-stay patterns.

05
Competitive In Progress

STR comp-set benchmarking — currently under construction in the live app.

06
Model Insights Access-Gated

Feature importance, error diagnostics, and the ML-vs-trailing-year-baseline comparison — gated in the live app since it surfaces hotel-specific performance data.

07
Rooms

Room-type-level forward view combining the forecast engine with current on-the-books pace.
